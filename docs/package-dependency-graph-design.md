# 包关联图设计文档

## 概述

包关联图（Package Dependency Graph）是静态分析系统中用于可视化包与包之间依赖关系的重要功能。它能够帮助开发者理解代码架构、识别循环依赖、发现架构问题等。

## 功能特性

### 1. 多种可视化方式

- **力导向图**：自然的网络结构，适合展示复杂依赖关系
- **环形布局**：包按圆形排列，清晰展示相互关系
- **层次布局**：分层显示，适合有明确层级的架构
- **和弦图**：展示包之间的双向依赖强度
- **桑基图**：流程式展示依赖流向

### 2. 智能筛选功能

- **复杂度筛选**：根据包复杂度阈值过滤
- **依赖强度筛选**：区分强依赖和弱依赖
- **包类型筛选**：内部包 vs 外部包
- **动态过滤**：实时更新图表显示

### 3. 交互式探索

- **节点选择**：点击查看包详细信息
- **关系高亮**：聚焦相邻依赖关系
- **缩放漫游**：支持图表缩放和拖拽
- **详情弹窗**：双击查看完整包信息

### 4. 统计分析

- **热点包识别**：按复杂度排序的 Top 包
- **依赖统计**：总包数、依赖关系数、强依赖数
- **复杂度分析**：平均复杂度计算
- **实时指标**：动态更新统计信息

## 数据结构

### PackageNode
```typescript
interface PackageNode {
  name: string              // 包名
  functionCount: number     // 函数数量
  internalCallCount: number // 内部调用数
  externalCallCount: number // 外部调用数
  complexity: number        // 复杂度 (0-1)
  subPackages: string[]     // 子包列表
}
```

### PackageDependency
```typescript
interface PackageDependency {
  sourcePackage: string     // 源包
  targetPackage: string     // 目标包
  callCount: number         // 调用次数
  dependencyStrength: number // 依赖强度 (0-1)
  callFunctions: string[]   // 调用的函数列表
}
```
